# Getting Started

This guide helps you set up the project locally and understand the development workflow.

## Prerequisites

- Linux environment
- bash shell (`/usr/bin/bash` assumed)

## Setup

1. Clone the repository.
2. Explore the `docs/` folder to learn the intended structure of the codebase and documentation.

## Project structure (planned)

```
docs/
  README.md
  getting-started.md
  usage.md
  api/README.md
  components/README.md
  examples/README.md
```

As source files are added (for example under `src/`), keep documentation synchronized by updating the relevant pages.
